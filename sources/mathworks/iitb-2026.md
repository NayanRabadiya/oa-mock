# MathWorks OA: IIT Bombay, 2026

Transcribed from a candidate's notes covering two MathWorks tests at IIT Bombay. Both were on HackerRank.

## Embedded Systems role

90 minutes, 27 questions:

- 25 MCQs on embedded systems, operating systems, computer architecture and aptitude (easy to medium). The questions themselves were not shared, so the mock leaves them out (listed under `offlist`).
- 2 coding questions:

### 1. Fewest IDs after removing m values

Given an array of IDs and an integer `m`, find the minimum number of distinct IDs left after removing `m` values.

Example: `arr = [1,3,1,4,1,1,1,2,2]`, `m = 2` → `2` (remove 3 and 4, leaving IDs 1 and 2).

→ `data/mathworks/questions/minids.json`. Assumed: exactly `m` elements are removed (as in LeetCode 1481). Constraints are the mock's.

### 2. Two values, at most k uses

Given `arr`, a `query` array and `k`, for each query find `a·arr[m] + b·arr[n] = query[i]` with `a + b ≤ k` and `a + b` minimal; `-1` if impossible.

Example: `arr = [1,2,3,6,67]`, `query = [1,4,30,70,89]`, `k = 5` → `[1,2,5,2,-1]` (e.g. 70 = 1·67 + 1·3, a + b = 2).

→ `data/mathworks/questions/twodenom.json`. The note wrote `ans[i] = a·arr[m] + b·arr[n]`, but the example output is the minimal `a + b`, so the mock asks for that. This is Codeforces 529D / 524C ("The Art of Dealing with ATM"); the mock uses its constraints (n ≤ 5000, k ≤ 20, q ≤ 20).

## Software Engineer role

3 coding questions. Solutions had to use at least two different programming languages across the three.

### 1. Minimum number of subsequences with a majority element

Partition the array into the fewest subsequences such that each has an element occurring strictly more than half its length. Every element belongs to exactly one subsequence.

→ `data/mathworks/questions/majparts.json`.

### 2. Count substrings that can be rearranged into palindromes

Given a vector of strings, for each one count the contiguous substrings whose characters can be rearranged into a palindrome.

→ `data/mathworks/questions/palsubs.json`. Assumed: substrings are non-empty and counted by position; letters are `a`–`z`.

### 3. Maximise beautiful substrings

A string of lowercase letters and dots: replace each dot with any letter to maximise the number of beautiful substrings (contiguous, all characters identical).

→ `data/mathworks/questions/beauty.json`. Assumed: substrings counted by position, so a block of L equal letters contributes L(L+1)/2.

No constraints, samples or time per question were reported for any of the five; the mock's are its own.
